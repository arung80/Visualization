# Visualization

Interactive math visualizations for students, published with GitHub Pages.

## Graphing Calculator

A browser-based graphing calculator simulator whose keypad follows the TI-84 Evo layout.

**Live:** https://arung80.github.io/Visualization/GraphingCalculator/

- Calculator: fractions, ◂▸ fraction/decimal toggle, trig in degree/radian mode, lists, Ans, store to variables
- Graphing: Y= editor, window, zoom (ZStandard, ZTrig, ZDecimal, ZSquare, ZoomFit, ZoomStat, ZBox), trace, table
- CALC menu: value, zero, minimum, maximum, intersect, dy/dx, ∫f(x)dx (with shading)
- Statistics: list editor, 1-Var / 2-Var Stats, LinReg, QuadReg, ExpReg, stat plots (scatter, xyLine, histogram, box plot)
- Distributions: normalpdf/cdf, invNorm, binompdf/cdf, poissonpdf/cdf, geometpdf/cdf
- Apps: equation solver, polynomial roots, system of equations, finance (TVM)

It is a single self-contained file (`GraphingCalculator/index.html`) with no dependencies. Lists, functions and settings are saved in the visitor's browser.
